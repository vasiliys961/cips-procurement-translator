# Переводчик CIPS

Речевой перевод переговоров специалиста по закупкам и поставщика. Основа — медицинский переводчик: живая речь идёт через модель, которая не принимает отдельные инструкции. После каждой фразы слой сверки сравнивает оригинал и перевод и предупреждает, если не сошлись цена, валюта, срок, Инкотермс, сторона, документ или платёжный инструмент.

CIPS — Chartered Institute of Procurement & Supply, Королевский институт закупок и поставок. Этот переводчик говорит на профессиональном языке закупок. Это не официальный сервис института.

Язык закупщика и язык поставщика фиксируются. **Слово поставщику** передаёт микрофон поставщику. **Слово закупщику** возвращает его. **Завершить** закрывает сессию.

## Запуск

```bash
cp .env.example .env.local
```

В `.env.local` нужны `OPENAI_API_KEY`, `AUTH_SECRET` и `TRANSLATOR_ACCESS_USERS`. Затем:

```bash
npm install
npm run dev
```

Откройте http://localhost:3002

## Тесты

```bash
npm test
```

## Автодиалог на одном устройстве

Переключатель **Автодиалог** включает отдельный режим с выбранной парой языков
(по умолчанию русский ↔ английский). Один раз нажмите **Начать** и говорите
по очереди. Пауза около секунды завершает реплику, непрерывная запись ограничена
20 секундами. Начало фразы сохраняется в локальном буфере примерно на 350 мс.
Направление определяется по языку каждой реплики: несколько русских реплик
подряд остаются направлением русский → английский. Своп не требуется.

Цепочка: локальный AudioWorklet/VAD → серверный `whisper-1` с определением языка
→ текстовый перевод → озвучивание → автоматическое возобновление записи.
При обработке и озвучивании микрофон приостановлен: дождитесь статуса «Слушаю».
Короткие неоднозначные ответы (`OK`, числа, отдельные сокращения) и речь вне пары
не переключают направление — приложение просит повторить более полную фразу.
Пара языков не определяется полностью автоматически: её нужно выбрать до начала.

Перевод использует правила сохранения закупочных терминов, чисел и обязательств;
существующая проверка fidelity показывает предупреждения под каждой репликой.
История последних десяти реплик остаётся в интерфейсе; каждая реплика переводится
отдельно. Внешний API вызывается только сервером после проверки входа.

Дополнительные настройки (необязательные):

```dotenv
AUTO_DIALOGUE_TEXT_MODEL=gpt-4o-mini
AUTO_DIALOGUE_TTS_MODEL=gpt-4o-mini-tts
```

`AUTO_DIALOGUE_TTS_MODEL` должен поддерживать `/v1/audio/speech`. По документации
OpenAI на 23.10.2026 используемый TTS доступен до 06.01.2027; до этой даты потребуется
миграция озвучивания на актуальный Realtime API, а не просто замена имени модели.
См. https://developers.openai.com/api/docs/guides/text-to-speech.

Нужны HTTPS (или localhost), разрешение на микрофон, AudioContext и AudioWorklet.
«Завершить», уход со страницы или скрытие вкладки останавливают запись,
отменяют запрос и проигрывание. Если браузер блокирует звук, нажмите
**Включить звук**; микрофон до окончания перевода остаётся приостановленным.
Названия нового режима переведены на русский и английский; для остальных языков
интерфейса новые подсказки пока показываются по-английски.

Расходы этого режима состоят из транскрипции, текстового перевода и TTS.
Фиксированный тариф/счётчик потокового режима здесь не применяется. Существующий
`usage` endpoint не списывает баланс; полноценный биллинг автодиалога не добавлен.
Ограничение одновременных запросов действует на пользователя в пределах процесса;
для нескольких серверов нужен общий лимитер.

### Проверка перед выпуском

Автотесты покрывают направление, паузы, предел реплики, WAV, остановку микрофона
и серверную обработку с подменой внешнего API. Проверки:

```bash
npm test
npx tsc --noEmit
npm run build
```

На реальном устройстве с API-ключом дополнительно проверьте:

1. Русский → английский → русский без свопа; начать может любая сторона.
2. Две реплики подряд на одном языке; направление не меняется.
3. Паузы внутри фразы, тихую речь и шум: порог локального VAD фиксирован,
   в шумном помещении или с тихим микрофоном может потребоваться настройка.
4. `OK`, числа, третий язык; просьбу повторить без ошибочной озвучки.
5. Перевод из динамика не запускает новый перевод.
6. Остановку во время разрешения микрофона, запроса и озвучивания; скрытие вкладки.
7. Safari/iPhone и Chrome/Android, включая кнопку разблокировки звука.
8. Пропадание сети, запрет микрофона и повторный запуск.

Живые вызовы OpenAI и акустическая проверка не входят в автоматические тесты.
